# Calculator Web App

A simple calculator web application built to practice programming logic and front-end development using modern web technologies.

## Features
- Basic arithmetic operations:
  - Addition
  - Subtraction
  - Multiplication
  - Division
- Clear/reset functionality
- Simple and clean user interface
- Responsive layout

## Technologies Used
- Svelte
- TypeScript
- HTML
- CSS

## Purpose
This project was created as a practice project to strengthen programming fundamentals, user interface design, and front-end development skills.
